# Database Management Systems (DBMS) Coursework & Capstone Project

This repository contains coursework, laboratory experiments, and the final capstone project for the **Database Management Systems (DBMS)** curriculum.

---

## 🏠 Capstone Project: HostelIQ — Smart Hostel Room Allocation Platform

The complete end-to-end Capstone Project is located in **[`Capstone Project/`](./Capstone%20Project)**.

- **Stack**: Next.js 16 (React 19, Tailwind CSS v4), Express 5, TypeScript, Prisma 6 ORM, MySQL 8.0 (InnoDB)
- **Live Demo**: [https://hostel-allocation-frontend-fyit.onrender.com](https://hostel-allocation-frontend-fyit.onrender.com)
- **Live Backend API**: [https://hostel-allocation-api-fyit.onrender.com](https://hostel-allocation-api-fyit.onrender.com)
- **MySQL Workbench Script**: [`Capstone Project/sql/hostel_allocation_db.sql`](./Capstone%20Project/sql/hostel_allocation_db.sql)
- **Documentation**: See full details, schema diagrams, and setup instructions in [`Capstone Project/README.md`](./Capstone%20Project/README.md).
